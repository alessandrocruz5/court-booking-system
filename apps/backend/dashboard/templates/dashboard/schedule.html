{% extends "dashboard/base.html" %} {% comment %} The schedule: a day grid of every court by hour, a booking side panel and the add form. Every value arrives from `dashboard.schedule`, already masked for the viewer's role, and every permission (`can_cancel`, `can_check_in`, `addable`) was decided on the server: the template only reflects it. The grid is one CSS grid (`.sg`). Each item is placed by line numbers from `dashboard.schedule` through the `.r-N` / `.rs-N` (row, row span) and `.c-N` / `.cs-N` (column, column span) classes in `dashboard.css`, and a booking is one block however many hours or rows it covers. Partials, rendered alone for htmx as `dashboard/schedule.html#`: grid the date nav and the grid (swapped into #grid), plus out-of-band toast and panel reset panel a booking's details, or a refusal message (swapped into #panel) form the walk-in / block form (swapped into #panel) No inline scripts, no hx-on, no inline styles: positions and colours are CSS classes. {% endcomment %} {% block dashboard_title %}Schedule{% endblock %} {% block dashboard_heading %}Schedule{% endblock %} {% block dashboard_content %}
